📘 Descripción general del sistema

Este proyecto corresponde al desarrollo de un sistema orientado a objetos en Java para la agencia de turismo Llanquihue Tour.
Su objetivo es organizar y representar la información de las personas relacionadas con la agencia, utilizando clases que permiten almacenar datos personales, direcciones e información de los empleados.
Durante su desarrollo se aplicaron conceptos fundamentales de programación orientada a objetos, como encapsulamiento, composición y herencia.

🧱 Estructura del proyecto

LlanquihueTour/

└── model/

├── Persona.java
└── Empleado.java

Descripción de las clases

Direccion: almacena calle, número, comuna y región.
Persona: almacena nombre, RUT, correo, teléfono y dirección.
Empleado: hereda de Persona y agrega cargo y sueldo.
Main: crea los objetos y muestra sus datos en consola.

⚙️ Instrucciones para ejecutar el proyecto

Clonar el repositorio desde GitHub.
Abrir el proyecto en IntelliJ IDEA.
Abrir Main.java, ubicado en el paquete app.
Ejecutar el método main.
Revisar los resultados en la consola.
